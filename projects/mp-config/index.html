mp-config

Ordered sources, profiles, property expansion, and typed configuration for Rust, inspired by Eclipse MicroProfile Config.

Get it

Available from source as a Git dependency. It is not published on crates.io.

  • Source

Notes

Values may come from properties files, TOML, environment variables, or custom sources. Ordinals and profiles determine precedence.

A derive macro builds typed, nested groups. Diagnostics show which source won and which values it shadowed.
