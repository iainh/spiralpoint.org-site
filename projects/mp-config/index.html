mp-config

Deterministic, typed layered configuration for Rust, with explicit precedence, profiles and value provenance.

Availability

Use mp-config from source as a Git dependency. It isn't published on crates.io.

  • Source code

Details

Values can come from properties files, TOML, environment variables or custom sources. Ordinals and profiles determine precedence.

A derive macro builds typed, nested groups. Diagnostics show which source won and which values it shadowed.
