mp-config

A Rust configuration library inspired by Eclipse MicroProfile Config. It combines ordered sources, profiles, property expansion, and typed conversion without a container or injection runtime.

Get it

The library is currently source-only and can be used as a Git dependency. It is not published on crates.io.

  • Source

Notes

Values can come from properties files, TOML, environment variables, or custom sources. Ordinals and profile-specific keys determine precedence, and resolved values retain their source information.

A derive macro builds typed, nested configuration groups. The diagnostic API can also explain which candidate won and which values it shadowed.
