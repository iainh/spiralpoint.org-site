bb8-ldap

Small, explicit and configurable pools of reusable asynchronous LDAP connections, built with bb8 and ldap3.

Availability

Version 0.4.1 is available on crates.io.

  • crates.io
  • Documentation
  • Source code

Details

The connection manager validates URLs first, optionally binds with credentials and checks pooled connections with a configurable, timeout-bounded LDAP search.

Connection and validation timeouts are independent. Use StartTLS over ldap:// with a selectable Rustls or native TLS backend; ldapi:// is also supported.
