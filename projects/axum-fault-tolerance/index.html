axum-fault-tolerance

Lightweight, composable fault-tolerance policies for asynchronous Rust, with predictable behaviour, precise, typed failures and an optional Tower layer.

Availability

Use axum-fault-tolerance from source as a Git or local path dependency. It isn't published on crates.io.

  • Source code

Details

Policies are Rust values or attributes on async methods. The core is independent of Axum; an optional Tower layer adapts it to services.

Error classifiers control retries, circuit breakers and fallbacks independently. Bulkheads reject work instead of queuing it.
