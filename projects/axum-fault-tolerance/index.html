axum-fault-tolerance

A Rust library for applying retries, timeouts, fallbacks, circuit breakers, and bulkheads to asynchronous work. It is modeled on Eclipse MicroProfile Fault Tolerance.

Get it

The library is currently source-only and can be used as a Git or local path dependency. It is not published on crates.io.

  • Source

Notes

Policies can be assembled as explicit Rust values or attached to async methods with attributes. The core works independently of Axum; an optional Tower layer adapts it to services.

Error classifiers independently decide which failures should be retried, counted by a circuit breaker, or passed to a fallback. Bulkheads reject immediately rather than keeping a wait queue.
