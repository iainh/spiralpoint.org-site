axum-health

A Rust library that adds aggregate, liveness, readiness, and startup health probes to Axum applications. Its endpoints and response format follow Eclipse MicroProfile Health.

Get it

The library is currently source-only and can be used as a Git dependency. The crate with the same name on crates.io is unrelated.

  • Source

Notes

Checks are asynchronous and run concurrently, while results stay in registration order. Failures become named DOWN entries and produce a 503 response rather than failing the request handler.

Checks can be registered as closures or generated from methods with an attribute macro. Diagnostic values support structured data, with guidance to keep secrets out of unauthenticated probe responses.
