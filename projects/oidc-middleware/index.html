oidc-middleware

Experimental OpenID Connect authentication and authorization for Axum. Tower layers cover bearer-token APIs and browser login, session, refresh, and logout flows.

Get it

Source and version tags are available on GitHub. The library is not currently published on crates.io.

  • Source

Notes

Token validation can use static keys, refreshable JWKS, introspection, UserInfo, or a custom validator. Requests can select among multiple OIDC tenants by path, issuer, or header.

Browser flows use encrypted state cookies, nonce-bound ID tokens, coordinated refreshes, bounded parsing, and explicit forwarded-header trust. The project is not security-audited.
