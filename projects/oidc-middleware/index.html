oidc-middleware

Standards-compliant OpenID Connect for Axum APIs and browser sessions, secure by default and built with explicit authorization boundaries.

Availability

Source code and version tags are on GitHub. The project isn't published on crates.io.

  • Source code

Details

Validate tokens with static keys, refreshable JWKS, introspection, UserInfo or custom code. Select tenants by path, issuer or header.

Browser flows include login, sessions, refresh and logout. The project has not been security audited.
