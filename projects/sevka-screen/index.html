sevka-screen

An outline interpretation of SGI IRIX's Screen 15 bitmap font, built reproducibly from Iosevka. It keeps the wide, vertically compact feel of the original 8×15-pixel cell without being a pixel-for-pixel trace.

Availability

TTF files for macOS and Windows in regular, medium and bold, each with a matching italic. A Latin-only WOFF2 package covers the web.

  • Windows fonts

Details

The build starts from Iosevka's ss11 preset, the X Window fixed forms, then picks letterforms to match Screen 15: a based 1, closed 4, double-storey a, single-storey g and curled y. Vertical metrics follow the original cell, programming ligatures are off, and arrowheads are enlarged so they stay readable at small sizes.

./scripts/build.sh downloads pinned Node.js and Iosevka versions into a local cache and builds all six styles, so a fresh checkout reproduces the shipped files without installing anything system-wide.

The macOS files are unhinted for CoreText. The Windows files are the same outlines run through ttfautohint for cleaner grid fitting at small sizes. Both packages share family metadata, so install one or the other, not both. Sevka Screen is released under the SIL Open Font License 1.1 and isn't an official SGI or Iosevka release.
