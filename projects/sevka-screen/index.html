sevka-screen

A fixed-width outline font built from Iosevka and shaped after the Screen 15 bitmap font used by SGI IRIX. It is an interpretation of the original rather than a direct conversion.

Get it

Ready-to-install TTF files are provided for macOS and Windows in regular, medium, and bold weights, with matching italics.

  • macOS fonts
  • Windows fonts
  • Source

Notes

The glyph forms and vertical metrics are tuned toward the compact proportions of the original 8×15-pixel cell. Programming ligatures are disabled.

The macOS files are unhinted. The Windows files use TrueType autohinting for small sizes; both packages share the same family metadata and should not be installed together.
