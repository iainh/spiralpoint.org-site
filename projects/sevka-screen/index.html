sevka-screen

A faithful, compact, and highly legible outline interpretation of SGI IRIX's Screen 15 bitmap font, reproducibly built from Iosevka.

Get it

TTF files for macOS and Windows in regular, medium, and bold, with matching italics.

  • macOS fonts
  • Windows fonts
  • Source

Notes

Glyphs and vertical metrics follow the original 8×15-pixel cell. Programming ligatures are disabled.

macOS files are unhinted; Windows files use TrueType autohinting. The two packages should not be installed together.
