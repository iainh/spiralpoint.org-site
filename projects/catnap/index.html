catnap

An asynchronous REST client library for Rust, inspired by Eclipse MicroProfile REST Client. Remote APIs are described as annotated traits and implemented by generated reqwest clients.

Get it

The crate is published on crates.io. Source is available on GitHub.

  • Crate
  • Source

Notes

The original trait remains the public interface. A procedural macro generates its client and rejects invalid HTTP declarations at compile time, including unmatched paths and bodies on GET requests.

Request and response filters, error mappers, query encoding, and optional XML support are built in. Raw responses remain streamable; typed responses are buffered for filtering and deserialization.
