catnap

Ergonomic, type-safe REST clients generated from Rust traits, with compile-time validation and explicit, extensible HTTP behaviour.

Availability

Use catnap from source as a Git dependency. It isn't published on crates.io.

  • Source code

Details

The trait remains the public interface. A procedural macro generates the client and rejects invalid HTTP declarations at compile time.

It includes request and response filters, error mapping, query encoding and optional XML support. You can still stream raw responses.
