catnap

Asynchronous REST clients generated from annotated Rust traits, inspired by Eclipse MicroProfile REST Client.

Get it

Available from source as a Git dependency. It is not published on crates.io.

  • Source

Notes

The trait remains the public interface. A procedural macro generates the client and rejects invalid HTTP declarations at compile time.

Includes request and response filters, error mapping, query encoding, and optional XML support. Raw responses remain streamable.
