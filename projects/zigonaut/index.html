zigonaut

A native Windows terminal written mostly in Zig, with ConPTY, tabs, and split panes.

Get it

Public downloads aren't available yet.

Notes

Zig manages the application and sessions; a small C++/WinRT bridge connects WinUI 3. Rendering uses Direct3D, Direct2D, and DirectWrite.

Ghostty handles terminal parsing. Matching ConPTY components ship with the application to avoid corruption during resize.
