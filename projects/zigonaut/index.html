zigonaut

A native terminal emulator for Windows, written mostly in Zig. It runs PowerShell, Command Prompt, WSL, and custom commands through ConPTY, with tabs and split panes.

Get it

Public downloads aren't available yet.

Notes

Zig manages the application and terminal sessions, with a small C++/WinRT bridge for WinUI 3. Rendering uses Direct3D, Direct2D, and DirectWrite; terminal parsing comes from Ghostty.

It ships matching ConPTY components alongside the application instead of relying only on the system copy. This avoids output corruption seen when resizing terminal rows and columns.
