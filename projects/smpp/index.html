smpp

Type-safe, specification-focused and performance-conscious SMPP 3.4 and 5.0 for asynchronous Rust, from high-level clients to protocol types.

Availability

Use smpp from source as a Git dependency. The crate with the same name on crates.io is unrelated.

  • Source code

Details

Strongly typed fields and comprehensive validation enforce SMPP wire rules. The allocation-conscious codec supports the complete 3.4 PDU set and 5.0 broadcast operations.

The asynchronous client includes version negotiation, keep-alives, structured tracing and congestion-aware flow control. The README declares the project MIT licensed; its referenced license file is currently absent from the repository.
