silica-mono

A monospaced TrueType font based on Geist Mono, with letterforms adapted from SGI's Screen 15 and programming symbols informed by JetBrains Mono.

Get it

The repository contains ready-to-install TTF files in regular, medium, and bold weights, with matching italics.

  • Font files and source

Notes

Screen 15's bitmap cells are traced into scalable outlines. The build preserves square corners on rectilinear glyphs instead of applying the same rounding everywhere.

Additional logic, set, proof, and arrow symbols are drawn for use in code. The output is a set of six static, autohinted fonts rather than a variable font.
