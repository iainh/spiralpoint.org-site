nucleotide

A graphical code editor that puts Helix's modal editing engine in a native desktop interface. It includes workspaces, a file tree, an integrated terminal, and remote development over SSH and WSL.

Get it

Packaged releases are available for Linux, macOS, and Windows. Windows builds are portable rather than installed.

  • Releases
  • Source

Notes

Nucleotide uses Helix's core crates directly rather than wrapping the terminal editor. The interface is built with GPUI, and its terminal uses Ghostty's terminal state machine.

Remote workspaces run file operations, language servers, terminals, and other processes through a helper on the remote machine. Remote targets are currently limited to Linux.
