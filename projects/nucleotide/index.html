nucleotide

Helix's modal editing engine in a native desktop interface, with workspaces, a file tree, a terminal, and remote development.

Get it

Packaged for Linux, macOS, and Windows. Windows builds are portable.

  • Releases
  • Source

Notes

Nucleotide uses Helix's core crates directly. The interface is built with GPUI; its terminal uses Ghostty's terminal state machine.

Remote workspaces use a helper for files, language servers, terminals, and processes over SSH or WSL. Remote targets must run Linux.
